Mounted read-only into the sender container. Expected layout (all gitignored):

    secrets/master.json        # funding wallet keypair (solana-keygen format)
    secrets/payers/*.json      # generated by `sender payers init`

    secrets/CLUSTER            # the one cluster these keys belong to (mainnet / devnet)
    secrets/devnet/...         # devnet keys: run with --secrets-dir secrets\devnet

The sender refuses a secrets dir bound to another cluster than the endpoint's (CLUSTER file,
written by `sender init-payers`; a folder named `devnet` / `mainnet` is bound on first use).

Never commit anything here except this README and .gitkeep.
